# Atlantico Preventivi Prototype

Static prototype for a preventivo automation flow:

- internal quote intake form
- live generated preventivo preview
- email preview with PDF attachment name
- approval / needs-edit demo state
- print-to-PDF flow

Assets were sourced from the public Atlantico Traslochi website for demo purposes.

Open `index.html` directly in a browser, or serve the folder with any static server.
